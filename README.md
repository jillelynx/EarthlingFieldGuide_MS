# Earthling Field Guide – Middle School Edition

A free browser learning game for Pennsylvania middle school science (grades 6–8), by J.E. Lynch.
Players explore as an alien field researcher and discover the vocabulary and key ideas of the PA STEELS
grades 6–8 standards for **3.1 Life Science** and **3.4 Environmental Literacy and Sustainability**.

It is the middle school companion to the high school game
[Earthling Field Guide](https://github.com/jillelynx/EarthlingFieldGuide).

Play: open `index.html` in a web browser, or visit the GitHub Pages site for this repository.
